** What next

From the "topics to study next" list:

1) *Machine learning:* That's what CS540 (Principles of AI) at CPU is
   for. There is an "Intro to AI" course for the undergraduates, too.

2) *Command-line skills* are key (especially for agentic AI - that's the
   main modus operandi for AI agents). My go-to book for that is
   William Shotts' The Linux Command-Line (yes, don't bother with
   Windows, please, and if you have a Mac, the terminal is a Linux
   clone). You can [[https://www.linuxcommand.org/tlcl.php][read this free online or buy the book]].

3) *Containerization* (the art of packing and shipping a portable
   environment or sandbox) is practically mostly done with
   Docker. DataCamp has a few good [[https://app.datacamp.com/learn/courses/introduction-to-docker][introductory courses]] on
   this. Though I actually recommend to just go to docker.com,
   download the beast, and play around with it. You can do that for
   free on Google Cloud Shell (it's already installed). Go through the
   Docker tutorial (using the CLI not the GUI). At the terminal
   prompt, just type =docker run hello-world=.

   [[https://github.com/birkenkrahe/os-26/blob/main/org/11_containers.org][In this lecture is a longer tutorial]] I just ran through with my
   (OS) students. It contains three simple demo applications.

4) *Full stack development*: As I said, this is going to be a fun field
   with AI. I'm going to meet with a student on Monday who is building
   a web development business for his customers in Peru, his native
   land, who want to sell stuff on the web in the US. He's a 100% vibe
   coder.

   How to get started? One of the Docker demos is creating a nifty web
   page (with a Python graph) and test it inside Google Cloud
   Shell. The best starting point is the free (!) [[https://www.freecodecamp.org/][freeCodeCamp]], or the
   [[https://www.theodinproject.com/][Odin Project]]. The latter is more challenging.

5) *Database programming*, especially the analytics side: Again,
   DataCamp is (for now) your friend (for the first steps). You need
   to learn SQL. DataCamp favors PostGreSQL, which I find too
   difficult but so what. My personal favorite is the lightweight
   SQLite. You are already using that because it's in every phone and
   in trillions of devices.

   On DataCamp, [[https://app.datacamp.com/learn/courses/introduction-to-sql?variant=traditional][start here directly with SQL]]. SQL is simple, and you
   can use DataLab to try stuff right away. Many sample databases
   there. KhanAcademy also has a free SQL course. freeCodeCamp is also
   good here but only videos + code along.

   For SQLite, use https://www.sqlitetutorial.net/. SQLite is cool and
   even easier than vanilla SQL (and not much different) because there
   is no user management to think of (which is a pain).

   I hope you enjoy these recommendations! Keep the questions and
   comments coming if you like.
