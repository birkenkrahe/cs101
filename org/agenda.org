** Bonus assignment "Program translator" (Q&A)

You had to translate a Java (or a Python) program into C++. The
program defined two variables and printed them using ~std::cout~.

- Your question (paraphrased):
  #+begin_quote
  What is the ~<<~ doing?
  #+end_quote

- *Answer:* We'll discuss this later in class: ~<<~ is the stream
  insertion operator. It inserts data into the output stream (that
  streams data to any device, e.g. a screen), represented by ~cout~, the
  standard output (~stdout~) object.

  So the chain printout command ~cout << "Hello" << 42 << endl;~
  1. inserts the string "Hello" into ~cout~
  2. inserts the integer 42 into ~cout~
  3. inserts ~endl~ (= newline + flush) into ~cout~.

  The idea of using a data stream makes data transfer (to the outside
  world) more general but also conceptually more difficult than just a
  C-style function like ~printf~, or a Java function like ~println~.

- Your question (paraphrased):
  #+begin_quote
  For the ~main~ program, I didn't use an argument like ~String[] args~. Why
  don't I need that in C++? Or should I have included it?
  #+end_quote

- *Answer:* You don't need it in C++, and you also don't need it in Java
  unless you want to pass arguments on the command-line to the program.

  The ~main~ function has an equivalent to the Java class argument
  ~String[] args~. It is ~main(int argc, char* argv[])~, and has two
  arguments that are actually easy to understand:
  1. ~argc~ is the number of arguments fed to the program
  2. ~argv[]~ is an array of strings that holds the arguments (an array
     of pointers to the beginning of each argument string) beginning
     with ~argv[0]~, which is the name of the program, and continuing
     with as many arguments that are passed to ~main~.

  *Background:* Java is tightly coupled to the JVM, the system that is
  shipped with it and ensures its portability (but also its
  slowness). C++ is closer to the operating system, which simply
  starts your program and optionally provides arguments.

- A *code example* use with command-line arguments looks like this:

  First the source code:
  #+begin_src C++ :tangle args.cpp :results none
    #include <iostream>
    #include <string>

    int main(int argc, char* argv[]) {
      // declare two strings
      std::string firstName, lastName;

      // print first command-line argument
      std::cout << "First name: " << argv[1] << std::endl
                << "Last name: "  << argv[2] << std::endl;
    }
  #+end_src

  The source code file =args.cpp= (tangled from the code cell above) is
  compiled, and then run on the command-line with two string
  arguments:

1) What do we want to know for a data structure?
   #+begin_quote
   1. What is its purpose?
   2. How are the data stored?
   3. How do you define it?
   4. How do you access it?
   5. How do you copy it?
   6. How do you extend it?
   7. How do you delete it?
   8. What else is worth knowing about it?
   #+end_quote

2) Can you answer these questions for C-style arrays?

   1. What is the purpose of an array?
      #+begin_quote
      An array stores values of only *one* data type (e.g. ~double~).
      #+end_quote

   2. How are data in an array stored?
      #+begin_quote
      An array stores its elements *contiguously* in memory, i.e. one
      memory cell directly on the next until the end is reached.
      #+end_quote

   3. How do you declare and define an array?
      #+begin_src C++ :main yes :includes :results none :exports both :noweb yes
        // data type + name + size = value list
        int array[5] {10, 20, 30, 40, 50};
      #+end_src

   4. How do you access an array?
      #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results output :exports both :noweb yes
        int numbers[6] {10, 20, 30, 40, 50, 60};
        // loop over array indices
        for (int i = 0; i < 6; i++)
          cout << numbers[i] << " ";
        puts("");
        // loop over the range of values
        for (auto num : numbers)
          cout << num << " ";
      #+end_src
     
   5. How do you copy an array?
      #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results output :exports both :noweb yes
        int numbers1[] {100,200,300};
        int numbers2[3]; // must specify size
        numbers2 = numbers1; // not allowed
        for (int i=0; i<3; i++)   
          numbers2[i]=numbers1[i]; // element-wise copy
        for (auto num : numbers2)
          cout << num << " ";      // print values
      #+end_src

   6. How do you extend an array?
      #+begin_quote
      You cannot extend an array at *run-time*, when the compiled
      program is executed, only at *compile-time* (in the source
      code). Alternative: use ~std::vector~.
      #+end_quote
     
   7. How do you delete an array?
      #+begin_quote
      An array is deleted automatically when it goes out of scope.
      #+end_quote

      #+begin_src C++ :main no :includes <iostream>  :namespaces std :results output :exports both
        #include <iostream>
        int main() {
          { // scope begins
            int num[3]={10,20,30};
            cout << num[0] << " " << num[1] << " " << num[2];
          } // scope ends
          cout << num[0] << " " << num[1] << " " << num[2]; // error: num is no
          // longer defined
          return 0;
        }
      #+end_src

   8. Where are arrays defined in C++?
      #+begin_quote
      C-style arrays are *built-in data structures*, no library is
      required. However, there is a special `std::array` container
      class, too, in the Standard Template Library (STL), which knows
      its ~size~, and can be copied as a whole.
      #+end_quote

   9. What else is worth knowing about arrays?

      - Out of bounds errors:
      #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results output :exports both :noweb yes
        int array[6] {10, 20, 30, 40, 50, 60};
        // loop over array indices
        for (int i = 0; i < 6; i--)
          cout << array[i] << " "; 
        // cout << array[6]; // segmentation fault
      #+end_src
     
3) On which different levels does C++ work with arrays?

   #+begin_src C++ :main yes :includes <iostream> <cstdlib> <string> <fstream> <vector> :namespaces std :results output :exports both :noweb yes
     std::string names[] {"James","Tori","Sam","Aliana", "Marcus"}; // defining a string array

     // Print strings using index [] operator
     for (int i=0;i<5;i++) cout << names[i] << " "; puts(""); // index level

     // Print string addresses using pointers to memory locations
     for (int i=0;i<5;i++) cout << names << " "; puts(""); // address (memory) level

     // Print array values using a range-based loop
     for (std::string name : names) cout << name << " "; // value (element) level
   #+end_src
